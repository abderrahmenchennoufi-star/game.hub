# Abderrahmen ch.

تطبيق ويب تقدمي (PWA) يعمل على أندرويد، مع إمكانية إضافته إلى الشاشة الرئيسية.

## الملفات
- `index.html`: التطبيق كاملًا.
- `manifest.json`: إعدادات التثبيت.
- `sw.js`: دعم العمل دون اتصال بعد أول تحميل.
- `icon-192.png` و`icon-512.png`: أيقونة التطبيق.

## التشغيل السريع
افتح `index.html` في متصفح لمعرفة شكل التطبيق. بعض ميزات التثبيت والعمل دون إنترنت تحتاج إلى نشر الملفات عبر HTTPS.

## التثبيت على أندرويد
1. ارفع الملفات إلى مستودع GitHub.
2. افتح Settings للمستودع ثم Pages، واختر النشر من الفرع الرئيسي (main) ومجلد الجذر (root).
3. افتح رابط GitHub Pages في Chrome على هاتفك.
4. من قائمة ⋮ اختر **Install app / تثبيت التطبيق** أو **Add to Home screen / إضافة إلى الشاشة الرئيسية**.

هذه نسخة PWA وليست APK مستقلًا. لبناء APK أصلي يمكن تغليف المشروع بأداة Android مثل Capacitor أو Android Studio.
